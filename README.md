### Hi, I'm Tom 👋

I'm passionate about programming and video games. I make **free and open-source Firefox add-ons** that do one thing well and respect your privacy: no account, no server of mine, no tracking. On the side, I make game mods, and one day I'd like to start my own video game studio.

Also: [middle-click-unload](https://github.com/Tom-Tour/middle-click-unload), a small Firefox tweak to unload a tab with a middle click instead of closing it.

Everything here is free and stays free ([GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html)). Bugs and ideas are welcome in each project's issues.
